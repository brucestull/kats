# Kats Django Project Setup Guide

This guide walks you through creating the **kats** Django host project—matching the structure and code at https://github.com/brucestull/kats — completely from scratch.

---

## 🛠️ Prerequisites

- **Python 3.10+** installed
- **pipenv** installed globally (`pip install pipenv`)
- Git installed (optional, for version control)

---

## 1. Create the Project Directory

```bash
mkdir kats
cd kats
```

---

## 2. Initialize Pipenv & Install Django

```bash
# Create a new venv with Python 3.10 (or your default Python)
pipenv --python 3.10

# Install Django
pipenv install django

# Activate the shell
pipenv shell
```

---

## 3. Start the Django Project

We’ll lay the project out under a `config/` directory:

```bash
django-admin startproject config .
```

Your directory should now look like:

```
kats/
├── Pipfile
├── Pipfile.lock
├── config/
│   ├── __init__.py
│   ├── asgi.py
│   ├── settings.py
│   ├── urls.py
│   └── wsgi.py
└── manage.py
```

---

## 4. Create Supporting Files & Folders

```bash
# Create a notes folder for dev docs
mkdir notes
touch notes/00_commands_and_links.md notes/chatgpt_project_creation.md

# Add a README, LICENSE, and Makefile
touch README.md LICENSE Makefile launch.json
```

## 6. Populate `config/urls.py`

Replace **all** of `config/urls.py` with:

```python
from django.contrib import admin
from django.urls import path, include

urlpatterns = [
    path("admin/", admin.site.urls),
    path("kittens/", include("kitten_corner.urls")),
    path("foods/", include("kat_food_corner.urls")),
    path("kats/", include("kat_corner.urls")),
]
```

## 7. `manage.py`, `launch.json`, and `Makefile`

**manage.py** (as generated):

```python
#!/usr/bin/env python
import os, sys

def main():
    os.environ.setdefault("DJANGO_SETTINGS_MODULE", "config.settings")
    from django.core.management import execute_from_command_line
    execute_from_command_line(sys.argv)

if __name__ == "__main__":
    main()
```

**launch.json** for VSCode (in `.vscode/launch.json` or at workspace root):

```json
{
    "version": "0.2.0",
    "configurations": [
        {
            "name": "Python: Django",
            "type": "python",
            "request": "launch",
            "program": "${workspaceFolder}/manage.py",
            "args": ["runserver"],
            "django": true,
            "justMyCode": true
        },
        {
            "name": "Python: Django Tests",
            "type": "python",
            "request": "launch",
            "program": "${workspaceFolder}/manage.py",
            "args": ["test"],
            "django": true,
            "justMyCode": true
        }
    ]
}
```

**Makefile** (example targets):

```makefile
.PHONY: run makemigrations migrate shell

run:
    pipenv run python manage.py runserver

makemigrations:
    pipenv run python manage.py makemigrations

migrate:
    pipenv run python manage.py migrate

shell:
    pipenv shell
```

## 8. Add `README.md`

``````markdown
# Kats 🐾

**Kats** is a Django skeleton project that integrates reusable "kat-themed" apps:

- Kat Corner – Manage kat records
- Kat Food Corner – Manage kat food and feeding
- Kitten Corner – Manage kitten records

## Project Structure

```

kats/
├── LICENSE
├── Pipfile
├── Pipfile.lock
├── README.md
├── config/
│   └── …
├── manage.py
└── notes/
├── 00\_commands\_and\_links.md
└── chatgpt\_project\_creation.md

```

## Getting Started

```bash
pipenv install --dev
pipenv shell
make makemigrations migrate run
````

## Installing Apps

```bash
pipenv install -e ../kats-kitten-corner/
pipenv install -e ../kats-kat-food-corner/
pipenv install -e ../kats-kat-corner/
```

## Common Commands

```bash
python manage.py makemigrations
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

## License

MIT License – see [LICENSE](LICENSE)

``````

### 🎉 Finish Up

1. **Migrations**  
    ```bash
    python manage.py makemigrations
    python manage.py migrate
    ```

2. **Run**

    ```bash
    python manage.py runserver
    ```

You should now have an identical codebase and structure to the official `kats` project!
